## 🤖 Featured Project

### PaulAI — AI-Powered Revit Copilot

An experimental AI-assisted Revit automation platform that allows users to interact with Autodesk Revit using natural-language instructions.

The system converts user requests into validated structured commands and executes supported operations through the Revit API.

**Architecture**

`Natural Language → Local LLM → Structured Command → Validation → Revit ExternalEvent → Revit API`

### Current Capabilities

- Select, count and isolate MEP elements
- Parameter-based element filtering
- Navigate and open Revit views
- Find sheets containing views
- Identify placed and unplaced views
- Create sheets and place views
- Export Revit sheets to PDF
- Manage open Revit view tabs
- Conversational clarification for incomplete commands

**Technology:**  
`C#` `Revit API` `.NET Framework` `WPF` `MVVM` `Ollama` `Qwen2.5` `JSON`

> A dedicated public showcase repository with demonstrations and architecture documentation is being prepared.
