# 🤖 Featured Project

## PaulAI — AI-Powered Revit Copilot

An experimental AI-assisted engineering application that enables users to interact with Autodesk Revit through **natural-language and voice-driven commands**.

Rather than allowing an LLM to execute uncontrolled operations, PaulAI converts user requests into structured commands, validates them, and executes only supported operations through a controlled Revit API workflow.

### Architecture

`Natural Language / Voice`

↓

`Local LLM / Command Parser`

↓

`Structured Intent`

↓

`Validation`

↓

`Revit ExternalEvent`

↓

`Revit API`

### Current Capabilities

- Select, count, and isolate MEP elements
- Filter elements using parameter conditions
- Diameter-based filtering for MEP elements
- Navigate and open Revit views
- Search views and sheets
- Find sheets containing requested views
- Identify placed and unplaced views
- Create sheets and place views
- Export active sheets to PDF
- Manage open Revit view tabs
- Conversational clarification for incomplete commands
- Voice-assisted multi-step Revit workflows

### Technology

`C#` · `.NET` · `Revit API` · `WPF` · `MVVM` · `Ollama` · `Qwen2.5` · `JSON` · `ExternalEvent`

🔗 **Repository:**  
https://github.com/Chayan-Paul/PaulAI-Revit-Copilot
